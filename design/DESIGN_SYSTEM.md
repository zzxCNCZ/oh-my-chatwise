# oh-my-chatwise · Forest Glass

这是项目持续使用的界面设计语言。基准见 `reference/ui-reference.png`，原始品牌素材见 `reference/logo-sheet.png`。后续聊天、设置、工具、存储、导入导出等界面均应遵循本规范。

## 品牌与素材

产品名称固定为 **oh-my-chatwise**，保持小写和连字符。应用标识和配置文件内部格式不随展示名称变更，确保已有数据、凭据与导出文件兼容。

品牌图形采用用户提供的双层绿色对话气泡与四角星标记，不另画星形替代、不改色、不拉伸、不去掉圆点。使用以下切片：

- `public/brand/logo-mark.png`：透明独立图形。
- `public/brand/wordmark.png`：原始字标。
- `public/brand/logo-lockup.png`：完整横版组合。
- `public/brand/app-icon.png`：圆角方形应用图标。
- `design/app-icon-source.png`：带光学留白的 1024 px 系统图标源。

切片由 `python3 scripts/slice-brand.py` 从原图确定性生成；运行 `pnpm tauri icon design/app-icon-source.png` 更新 macOS / Windows 图标。界面使用 `AppIcon` 和 `BrandLogo`，避免重复嵌入或生成不一致的替代品。浅色模式使用原始字标；深色模式保留原图形，以白色/绿色文字保证品牌名可读。图标只是身份标识，不表示某个供应商。

## 视觉基调

轻盈、安静、自然。浅色磨砂与薄雾绿为主，绿色渐变只用于主操作和品牌焦点。保留同体系深色模式，不覆盖已有用户的主题选择。应用默认浅色。

- 环境层：柔和绿白渐变，避免把参考图的桌面壁纸作为聊天背景。
- 导航层：半透明薄雾绿侧栏，细边线和背景模糊。
- 内容层：接近白色、留白充足，以文字阅读为中心。
- 浮层：磨砂白卡片、柔和大阴影、清晰的层级。
- 主按钮：深浅绿色渐变、白色文字与轻微内高光。
- 危险操作保持语义红色，不使用品牌绿色。

统一变量在 `src/styles/tokens.css`。结构和功能组件基础样式在 `base.css`；Forest Glass 视觉规范在 `glass.css`；`src/style.css` 只编排导入顺序。新增组件复用这些变量，不在各页面重复定义主题。

## 布局与比例

桌面双栏。侧栏标准 280 px、大屏 300 px、小屏 248–260 px；顶栏 82 px。窗口控件由操作系统提供，不在网页绘制假的红黄绿按钮。

- 侧栏：品牌、绿色新对话、独立搜索、按日期分组的记录、工作空间卡片、本地用户设置入口。
- 当前记录：淡绿选中底色、3 px 绿色竖条；未悬停时展示简短时间，悬停/键盘操作时显示更多操作。
- 顶栏：应用图标与模型选择器；右侧工作空间入口、真实状态和参数操作。
- 聊天：用户消息靠右使用薄雾绿气泡；助手内容保持通透，头像、名称和时间建立身份层级。
- 输入框：26 px 圆角、双层浅色边缘、宽松文字区；图片/链接/文件/提示词/工具分开；绿色圆形发送按钮。
- 设置：与聊天一致的双色双栏浮层，禁止出现单独一套深灰设置面板。

在 760 px 桌面最小窗口、窄浏览器窗口和大屏检查布局。空间不足时隐藏次要状态文字、收起侧栏或横向滚动工具入口，不遮挡发送按钮和必需操作。

## 字体与细节

使用系统无衬线字体及中文系统字体。正文 14 px、1.9 行高；模型名/身份 14 px；标题 22–33 px；辅助信息 10–12 px。避免整页使用低对比度小字。代码使用系统等宽字体，单独的浅色代码面板、语言标题和复制操作；高亮颜色随主题切换。

圆角尺度：8 / 12 / 18 / 26 px。间距尺度：4 / 8 / 12 / 16 / 24 / 32 px。边线细而克制；不堆叠高强度描边或绿色大面积填充。

图标统一使用现有 Lucide 图标。交互保持 160 ms 左右的轻反馈，并尊重 `prefers-reduced-motion`。键盘焦点可见，所有纯图标操作有可读标签，禁用状态明确。

## 真实状态与功能边界

参考图是视觉依据，不代表新增账户、会员、供应商或本地推理功能。显示实际的配置/生成状态；不把已选择模型等同于 API 健康检查成功。不伪造 PRO 会员、工具执行结果或网络连接状态。界面验证示例仅放在独立测试目录，不写进用户工作空间或产品默认数据。

改动视觉时保留现有会话、图片、文本解析、三种 API、工具执行与授权、标题生成、同步冲突、加密配置迁移等功能。不要因品牌更名修改 `com.zexinzhuang.oh-my-chatwise`、凭据命名或已有导出格式。
